# NOMAD Question Hub

Отдельный временный сервис анонимных опросов. Он не подключён к основной БД и runtime-коду NOMAD.

## Что внутри

- `apps/survey` — публичная анкета из 15 вопросов без регистрации и идентификации клиента;
- единая тёмная премиальная тема без светлого варианта и переключателя;
- `apps/results` — отдельная закрытая паролем панель владельца;
- проценты, средние оценки и рейтинги считаются обычным детерминированным алгоритмом;
- Groq обрабатывает только два свободных текстовых поля, NVIDIA используется как резерв;
- новый текст объединяется с накопленным ИИ-резюме;
- каждую исходную анкету можно раскрыть в кабинете владельца;
- повторное заполнение намеренно разрешено.

## Локальный запуск

```bash
npm install
copy apps\survey\.env.example apps\survey\.env.local
copy apps\results\.env.example apps\results\.env.local
npm run dev:survey
```

Анкета будет на `http://localhost:3000`. Для панели во втором терминале выполнить `npm run dev:results`; она откроется на `http://localhost:3001`.

## Отдельная база на Render

1. Создать новый PostgreSQL на Render. Web Service для этого проекта не нужен.
2. Скопировать внешний PostgreSQL URL.
3. Добавить его в переменные проекта Vercel как `DATABASE_URL`.

Таблицы и индексы создаются автоматически при первом обращении к API. Существующая БД NOMAD не используется.

## Переменные Vercel

В проекте **survey**:

```text
DATABASE_URL=postgresql://...
SURVEY_CYCLE=2026-Q3
```

В проекте **results**: тот же `DATABASE_URL` и тот же `SURVEY_CYCLE`, а также:

```text
RESULTS_PASSWORD=пароль владельца
SESSION_SECRET=случайная длинная строка
```

Для обработки свободных ответов ИИ-ключи добавляются в оба проекта. Достаточно Groq или NVIDIA. Если настроены оба, Groq используется первым, NVIDIA — при ошибке основного провайдера:

```text
GROQ_API_KEY=...
GROQ_MODEL=openai/gpt-oss-120b
NVIDIA_API_KEY=...
NVIDIA_MODEL=openai/gpt-oss-120b
```

Для каждого нового квартального запуска меняется только значение:

```text
SURVEY_CYCLE=2026-Q3
```

Старые циклы остаются в БД, а кабинет показывает цикл, указанный в текущей переменной.

## Развёртывание на Vercel

Создать **два отдельных Vercel-проекта из одного GitHub-репозитория**:

1. В первом указать Root Directory: `apps/survey`. Это ссылка, которую получают клиенты.
2. Во втором указать Root Directory: `apps/results`. Это отдельная ссылка владельца для просмотра результатов.
3. В обоих добавить `DATABASE_URL`, одинаковый `SURVEY_CYCLE` и ИИ-ключи. В results дополнительно добавить `RESULTS_PASSWORD` и `SESSION_SECRET`.

Отдельный backend на Render не нужен: API-маршруты работают как Vercel Functions, а Render предоставляет только отдельную PostgreSQL БД.

## Анонимность

Приложение не запрашивает и не записывает имя, телефон, email, IP-адрес, User-Agent или идентификатор устройства. Перед отправкой текста в ИИ из него дополнительно маскируются телефоны, email и ссылки. Клиенту всё равно предлагается не писать личные данные в свободных полях.
